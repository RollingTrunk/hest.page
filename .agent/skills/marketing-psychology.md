# Marketing Psychology Guidelines

## Core Mental Models
- **Loss Aversion**: People prefer avoiding losses to acquiring equivalent gains. Frame messaging around what users lose by *not* using Hest.
- **Social Proof**: Leverage testimonials, usage stats, and "featured in" badges to build trust.
- **Anchoring**: Use high-value reference points to make pricing or time-savings feel like a steal.

## Ethical Implementation
- **First Principles**: Focus on the fundamental truths of the user's problem (e.g., "Family chaos causes stress") rather than just features ("We have a calendar").
- **Analysis**: When making decisions, ask: "What psychological trigger is this tapping into?"
- **Honesty**: Never use dark patterns. influencing behavior should favor the user's long-term goals.

## Application
- **Landing Pages**: Use "Pain-Agitate-Solution" frameworks.
- **Copy**: Focus on benefits (emotional outcome) over features (technical implementation).
